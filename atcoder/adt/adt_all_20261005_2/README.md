## D. Line Sensor

ある行列$H\times W$が与えられて、`#`があったら、箱がその座標に置かれている。`.`があったら、空マスである。列ずつの箱数を求めよ。

これは問題になれないと思いますが、`cin`から入力を読み込んでいるところにも計算できます。それに、APLのような配列言語を使ったら、配列を転置してマスクしてから和関数で削減すればいいです。[Uiuaの提出](https://atcoder.jp/contests/adt_all_20261005_2/submissions/79814847)も載っていました。


## E. Sum of Product

長さ$N$の数列$A=(A_1,A_2,...,A_N)$のペアごとの積の総和を求めよという問題文です。もっと厳密に、$\Sigma_{1\leq i < j \leq N}A_iA_j$を求めよ。

例えば、$A=(1,2,3,4)$であれば、$A_1A_2+A_1A_3+A_1A_4+A_2A_3+A_2A_4+A_3A_4 = 36$.
Pythonの`itertools.combinations`でも解けると思いますが、累積和配列でも計算できると気づきました。

$$
A=(1,2,3,4); S=(10,9,7,4)
$$

尾から総和を求めてから、$1 \leq i < N$を満たす任意の$i$で、$A_iS_{i+1}$になります。この方法で、二周では十分です。

## G. Election Quick Report

$N$の候補者を$1$から$N$を呼び、$M$の選挙投票があり、投票を読むごとにその時点誰が勝っているのかを出せよという問題文です。

```plaintext
3 7
1 2 2 3 1 3 3
```

正解のは、

```plaintext
1
1
2
2
1
1
3
```

投票ずつ進めば、`1`が開票され、$(1,0,0)$となり、一番目の候補者が勝っているので`1`を出します。それで、以下のように、

- `2`が開票され、$(1,1,0)$となりながら、二人が勝っているので、小さい番号のほうで、`1`を出します。
- `2`が開票され、$(1,2,0)$となり、今は逆転で二番目の候補者が勝っているようになったので、`2`を出します。
- 同じく繰り返す。

投票を開票すると、票数を更新し、再び最大値を求めるというシミュレートすればTLEですね。しかし、問題文によると、開票する時点のステート知る必要はなく、ただ誰が一番だと求めています。それで、どうやってステートを更新しても、最速に最大値を求められるのかの問題になってきました。

C++の`set`ではいいと思います、いつもソート済み状態であり、$i$番目の候補者の票数を更新したいときには、$(n,i)$を削除して、$(n+1,i)$を追加してはいいです。
