## G. Add One Edge

二つのグラフが与えられ、一つのグラフが$1,...,X$というノードを含み、一つが$X+1,...,N$というノードを含みます。ただ一つの辺で、二つのグラフをつなげると、$1$から$N$までの最長距離を求めよ。

このパターンは、$1$から$N$までの経路は、いつも$1$から1つ目のグラフのある$u$を通り、それで$uv$という新しい辺を通り、2つ目のグラフにある$v$というノードから$N$までの経路を通らなければなりません。なので、Dijkstraで、$1$から他の全部のノードに最短距離を求めながら、同じく$N$からのも求めます。

それで、$D(1,u) + 1 + D(v,N)$の最大値を求めれば済むのです。成長したのでしょうかな。
